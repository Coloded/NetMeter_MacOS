# NetMeter 1.1.2

## English

- Compact menu-bar indicator: download on the first row, upload on the second. Full B/s, KB/s, MB/s and GB/s units retained.
- Hover to see the monitored interface, current download/upload speeds, session traffic and lifetime traffic totals.
- Tooltip text translated into all four interface languages. Native template rendering adapts to light and dark menu bars.

Requires macOS 13 or later; Universal for Apple Silicon and Intel. Developer ID notarization is not configured.

## Русский

- Компактный индикатор в строке меню: загрузка сверху, отдача снизу. Полные единицы B/s, KB/s, MB/s и GB/s сохранены.
- При наведении: отслеживаемый интерфейс, текущая загрузка и отдача, объём трафика за сеанс и всё время.
- Подсказка переведена на четыре языка. Индикатор адаптируется к светлой и тёмной строке меню.

Требуется macOS 13 или новее; Universal для Apple Silicon и Intel. Notarization через Developer ID не настроена.
